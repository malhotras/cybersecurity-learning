\# IPv4 vs IPv6



\*\*IPv4\*\* and \*\*IPv6\*\* are versions of the Internet Protocol used to identify network interfaces and route network traffic.



\## IPv4



IPv4 uses \*\*32-bit addresses\*\*.



Example:



`192.168.1.10`



IPv4 has approximately \*\*4.3 billion possible addresses\*\*.



An IPv4 address is usually written as four decimal numbers separated by periods.



Example:



`192.168.0.1`



\---



\## IPv6



IPv6 uses \*\*128-bit addresses\*\*.



Example:



`2001:db8:1234::10`



IPv6 provides a vastly larger address space than IPv4.



IPv6 addresses are written using hexadecimal numbers separated by colons.



Example:



`2001:db8:85a3::8a2e:370:7334`



\---



\## Comparison



| Feature       | IPv4           | IPv6                     |

| ------------- | -------------- | ------------------------ |

| Address size  | 32-bit         | 128-bit                  |

| Example       | `192.168.1.10` | `2001:db8::10`           |

| Notation      | Decimal        | Hexadecimal              |

| Address space | \~4.3 billion   | \~3.4 × 10³⁸              |

| Broadcast     | Supported      | No traditional broadcast |



\---



\## Why was IPv6 introduced?



The number of devices connected to the Internet increased significantly, creating pressure on the limited IPv4 address space.



IPv6 provides a much larger address space and was designed with several improvements to the Internet Protocol.



\---



\## Can IPv4 and IPv6 work together?



Yes.



A device or network can support both protocols at the same time. This is commonly called \*\*dual stack\*\*.



For example, a computer might have:



```text

IPv4: 192.168.1.10

IPv6: 2001:db8::10

```



\---



\## Security considerations



Both IPv4 and IPv6 require appropriate security controls.



Important areas include:



\* Firewall configuration

\* Access control

\* Secure network architecture

\* Monitoring

\* Proper routing configuration



A network should not assume that disabling or ignoring IPv6 automatically makes it secure.



\---



\## Key takeaway



> \*\*IPv4 uses 32-bit addresses, while IPv6 uses 128-bit addresses.\*\*



The main reason IPv6 was developed was to provide a vastly larger address space and support the continued growth of Internet-connected devices.

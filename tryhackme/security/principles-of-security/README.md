# Principles of Security

## Overview

**Principles of Security** is a TryHackMe room covering fundamental information security concepts and how they are applied to protect information systems.

The room covers:

- The CIA Triad
- Principles of Privileges
- Security Models
- Threat Modelling
- Incident Response

## Topics

### 1. CIA Triad

The three fundamental principles of information security:

- **Confidentiality** — protecting information from unauthorised access
- **Integrity** — protecting information from unauthorised modification
- **Availability** — ensuring authorised users can access information when needed

## Key Takeaways

- The **CIA Triad** provides three fundamental goals for information security.
- **Least Privilege** means giving users only the permissions they need.
- **PIM** maps organisational roles to system access roles, while **PAM** manages the privileges of those roles.
- **Bell-LaPadula** focuses on confidentiality.
- **Biba** focuses on integrity.
- **STRIDE** is a framework for identifying common threats.
- **Incident Response** provides a structured process for dealing with security incidents.

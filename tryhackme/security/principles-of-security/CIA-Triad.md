# CIA Triad

The **CIA Triad** is a fundamental information security model consisting of three principles:

- **Confidentiality**
- **Integrity**
- **Availability**

## 1. Confidentiality

Confidentiality ensures that information is only accessible to authorised people or systems.

### Key question

> Who is allowed to access the information?

### Examples

- Access controls
- Encryption
- Authentication
- Data classification

---

## 2. Integrity

Integrity ensures that information remains accurate and cannot be modified by unauthorised people.

### Key question

> Has the information been changed without authorization?

### Examples

- Access controls
- Authentication
- Hash verification
- Digital signatures

---

## 3. Availability

Availability ensures that authorised users can access information and systems when they need them.

### Key question

> Can authorised users access the information when needed?

### Examples

- Reliable hardware
- Backups
- Redundant systems
- Protection against denial-of-service attacks

---

## Questions

### Q1. What element of the CIA triad ensures that data cannot be altered by unauthorised people?

**Answer:** `Integrity`

Integrity protects information from unauthorised modification and helps ensure that data remains accurate and consistent.

### Q2. What element of the CIA triad ensures that data is available?

**Answer:** `Availability`

Availability ensures that authorised users can access information and systems when they need them.

### Q3. What element of the CIA triad ensures that data is only accessed by authorised people?

**Answer:** `Confidentiality`

Confidentiality protects information from unauthorised access and disclosure.

---

## Quick Reference

| Principle | Main question |
|---|---|
| **Confidentiality** | Who can access the data? |
| **Integrity** | Has the data been changed without authorization? |
| **Availability** | Can authorised users access the data when needed? |

## Key Takeaway

The CIA Triad provides three fundamental goals for protecting information:

**Confidentiality → Integrity → Availability**
